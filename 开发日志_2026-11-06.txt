七、踩坑记录（重要，按被发现顺序）
----------------------------------------------------------------
坑 1：KivyMD 2.0 与网上教程不兼容
    现象：ImportError: cannot import name 'MDRaisedButton'
    原因：2.0 删除了 1.x 的按钮组件，字体样式也从 "H5" 改成 role
    解决：自绘按钮；字体用 font_size 或 font_style="Headline"

坑 2：中文显示成方块
    原因：Kivy 默认字体 Roboto 没有中文字形
    解决：LabelBase.register(name="Roboto", ...) 替换成中文字体
          电脑用 C:\Windows\Fonts\msyh.ttc，手机用项目内 Noto Sans CJK SC

坑 3：libffi 在 Ubuntu 24.04 编译失败
    现象：configure.ac:215: error: possibly undefined macro: LT_SYS_SYMBOL_USCORE
    原因：Ubuntu 24 的 libtool 2.4.7 与 p4a 自带的旧 libffi 不兼容；
          同时 p4a 新版默认用 Python 3.14，Kivy 2.3.1 支持不好
    解决：构建机换 ubuntu-22.04 + 固定 p4a==2024.1.21

坑 4：安卓打包找不到入口
    现象：BUILD FAILURE: No main.py(c) found in your app directory
    解决：新增 main.py（内容：from app import CareerApp; CareerApp().run()）

坑 5：Gradle 要 Java 17，构建机给的是 Java 11
    现象：Android Gradle plugin requires Java 17 to run
    解决：构建步骤 env: JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64

坑 6（最隐蔽）：运行时缺 asyncgui
    现象：APK 能装能开首页，一点测试立刻闪退，无系统弹窗
    定位：adb logcat 里看到 Python Traceback →
          ModuleNotFoundError: No module named 'asyncgui'
    原因：KivyMD 的 appbar 在运行时 import asynckivy，
          而 asynckivy 依赖 asyncgui，buildozer 的 requirements 漏了它
    解决：requirements 补 asyncgui==0.6.3
    教训：构建成功 ≠ 能运行；KivyMD 的依赖必须在 requirements 里列全，
          光看 CI 日志发现不了，必须真机抓日志

坑 7（环境类）：github.com 访问不稳定
    现象：浏览器 ERR_CONNECTION_TIMED_OUT / 已重置连接
    原因：默认 IP 被封，且封禁会轮换
    解决：扫描可用 IP 写 hosts；最终改用 SSH over 443 推送

坑 8（环境类）：构建机下载 Ant 被重置
    现象：urllib.error.URLError: Connection reset by peer
    解决：重跑 workflow


八、复现指南（从零开始）
----------------------------------------------------------------
步骤 1：装 Python 3.13（Kivy 2.3.1 只提供到 cp313 的预编译包）
    winget install --id Python.Python.3.13 -e --scope user
    py -3.13 --version

步骤 2：装依赖
    py -3.13 -m pip install kivy==2.3.1 kivymd==2.0.0 pyinstaller

步骤 3：拿到项目
    git clone https://github.com/IDchunjie/career-test.git
    （或用 E:\career_app 现有目录）

步骤 4：电脑上运行
    py -3.13 app.py

步骤 5：打包 Windows exe（可选）
    py -3.13 -m PyInstaller --noconfirm --windowed --onefile ^
        --name CareerTest --add-data "data.json;." ^
        --hidden-import kivymd.icon_definitions --collect-data kivymd app.py

步骤 6：打安卓包（推荐云端）
    把代码推到 GitHub 的 main 分支，Actions 会自动构建；
    workflow 关键点：
        runs-on: ubuntu-22.04
        pip install buildozer cython
        pip install python-for-android==2024.1.21
        env JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64
        buildozer -v android debug
    产物在 Actions 运行页的 Artifacts 里下载。

步骤 7：装到手机
    先卸载旧版（debug 签名每次不同），再安装新 APK；
    需要允许“安装未知应用”；首次启动等 10~20 秒。
